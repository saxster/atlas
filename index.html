Six ways to work a figure

  • Book. Scroll turns the page and the camera moves; click a part to break it down. Example
  • Machine. Numbered steps, one live at a time, Manual or Auto, with optional section cuts. Example
  • Explorer. Predict first, then drag the sliders and run it against live 2D charts. Example
  • Sandbox. Place, drag or wire pieces in 3D, enter matrices, and undo resets cleanly. Example
  • Teardown. Explode multi-part mechanisms and hardware assemblies without cutting solids. Example
  • Blueprint. Watertight CSG floorplans, orthographic hatching, dimensions, and section cuts. Example

Start

npm install github:saxster/atlas three
npx atlas new biology/heart --grammar machine
npx atlas boot bugged-sketchbook

That writes a pure model.js, its independent checks.mjs, the figure and a page. Coding agents can read llms.txt or llms-full.txt directly.

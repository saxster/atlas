AtlasExamplesSource

Teaching figures for any subject.

A small library: write the model, say what to draw, and get a 3D paper-and-ink figure a reader can work

Three ways to work a figure

  • Book. Scroll turns the page and the camera moves; click a part to break it down. Example
  • Machine. Numbered steps, one live at a time, Manual or Auto. Example
  • Explorer. Predict first, then drag the sliders and run it. Example

Start

npm install github:saxster/atlas three
npx atlas new biology/heart --grammar machine

That writes a model, its checks, the figure and a page. Every number on screen comes from the model, and the checks prove the model a second way.

Built with it

Nineteen figures across physics, maths, chemistry, statistics and economics, and an index of ideas that cross subjects.
